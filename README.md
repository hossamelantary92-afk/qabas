# قبس | Qabas — نسخة أولية قابلة للتشغيل

موقع مسابقات إسلامية باللغة العربية (RTL)، مصمم ليعمل على جوال واحد بين مجموعة أصدقاء، دون تسجيل حسابات أو تثبيت أدوات.

## التشغيل والنشر

- افتح ملف `index.html` بواسطة خادم محلي (مثل `python -m http.server 8000`) ثم افتح `http://localhost:8000`.
- يمكنك رفع **محتويات هذا المجلد** إلى مستودع GitHub ثم اختيار المستودع في Vercel. إعدادات Vercel: Framework Preset = Other، بدون Build Command، وOutput Directory = `.`.
- البيانات محفوظة محليًا في متصفح الجهاز باستخدام `localStorage`؛ لا توجد قاعدة بيانات أو تزامن متعدد الأجهزة.

## المميزات المنفذة

- هوية زمردية وذهبية متجاوبة مع الجوال، شعار SVG وملف Web App Manifest.
- لعب حر أو مسابقة شاملة، أفراد أو فرق، إضافة الأسماء وتغييرها، اختيار الألعاب والموضوعات والصعوبة.
- ست ألعاب: تحدي المعلومات، من أنا، الدقيقة، خطف الإجابة، اختار مستوى التحدي، البطاقات الجماعية.
- كشف الإجابة مع المصدر، نقاط، لوحة نتائج قابلة للتعديل، جولة ذهبية وسؤال فاصل عند التعادل، حفظ الجلسة.

## حدود هذه النسخة

- هذه نسخة MVP وليست بنك الـ600 سؤال النهائي. تضم أسئلة مكتوبة خصيصًا للنسخة التجريبية، ولكل سؤال إشارة إلى مصدر، لكن المراجعة الدينية والتحريرية النهائية والتدقيق المرجعي لم تكتمل بعد. لا تستخدمها للنشر العام بصفتها بنكًا معتمدًا قبل المراجعة.
- تلميحات «من أنا» متاحة للشخصيات التي أُعدت لها تلميحات؛ هذا الوضع يسحب من هذه المجموعة أولًا.
- وضع «الدقيقة» يستخدم مؤقتًا يعمل أثناء فتح الصفحة؛ متصفحات الهواتف قد توقف المؤقت في الخلفية.
- لا يتم تفعيل الصوت أو قاعدة بيانات Firebase حتى الآن. لا توجد صور لتمثيل الأنبياء.
